# Git Handbook

A practical reference for everyday Git: one page per command, with its usage, plus answered questions for common situations.

- **[commands/](commands/)**: a reference page for each Git command
- **[Q&A discussions](../../discussions/categories/q-a)**: short answers to common Git questions ("how do I undo...", "how do I find...")
