# git survey

## Usage

```text
usage: (EXPERIMENTAL!) git survey <options>

    -v, --[no-]verbose    verbose output
    --[no-]progress       show progress
    -n, --[no-]top <n>    number of entries to include in detail tables
    --all-refs            include all refs
    --branches            include branches
    --tags                include tags
    --remotes             include all remotes refs
    --detached            include detached HEAD
    --other               include notes and stashes
```

See also: `git help survey`.
