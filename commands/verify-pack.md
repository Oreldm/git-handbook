# git verify-pack

## Usage

```text
usage: git verify-pack [-v | --verbose] [-s | --stat-only] [--] <pack>.idx...

    -v, --[no-]verbose    verbose
    -s, --[no-]stat-only  show statistics only
    --[no-]object-format <hash>
                          specify the hash algorithm to use
```

See also: `git help verify-pack`.
